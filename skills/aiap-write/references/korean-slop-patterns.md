# 한국어 AI 슬롭·번역투 패턴

이 플러그인의 게이트가 실제로 검출하는 패턴이다. **서버측 정규식과 일치해야 하므로
임의로 추가하지 마라** — 서버가 모르는 패턴을 스킬에만 넣으면 게이트는 통과시키고
스킬만 막는 불일치가 생긴다. 규칙 변경은 서버(`AIAP_Writing_Guide`)에서 한다.

## S1 — 즉시 수정 (1회만 나와도 발행 거부)

### 번역투

| 패턴 | 문제 | 교정 |
|---|---|---|
| `~에 대해(서)` | 영어 about/regarding 직역 | 목적격 조사로 |
| `~를 통해(서)` | 영어 through 직역 | `~로`, `~에서` |
| `~에 의해` | 수동태 직역 | 능동으로 |
| `~에 있어서` | 영어 in terms of 직역 | `~에서`, `~의 경우` |
| `되어진다` / `되어졌다` / `되어집니다` | 이중 피동 | `된다` / `집니다` |
| `가지고 있다` / `가지고 있습니다` | have 직역 | `있다` / `있습니다` |
| `라고 할 수 있다` / `라고 할 수 있습니다` | hedging 직역 | 단정하거나 삭제 |

**예시**

```
❌ 물가에 대해 설명하고, 지수를 통해 흐름을 파악할 수 있습니다.
✅ 물가를 설명하고, 지수로 흐름을 파악할 수 있습니다.

❌ 이 지표는 전문가에 의해 검증되어집니다.
✅ 이 지표는 전문가가 검증합니다.

❌ 각 항목은 고유한 의미를 가지고 있습니다.
✅ 각 항목은 의미가 다릅니다.

❌ 이는 중요한 시사점이라고 할 수 있습니다.
✅ 이는 중요한 시사점입니다.  (또는 문장 삭제)
```

> **합니다체 주의**: 이 플러그인은 합니다체 글을 생성한다. 평서형(`되어진다`)만
> 보고 넘기면 `되어집니다`·`가지고 있습니다` 를 전부 놓친다. **활용형을 함께 확인하라.**

### 발명·템플릿 잔여어

## S2 — 3회 이상 반복되면 등급 하락

### AI 상투 어휘

| 표현 | 문제 |
|---|---|
| `결론적으로` | 결론을 예고만 하고 내용이 없는 경우가 많다 |
| `다양한 측면에서` | 구체성 없음 |
| `매우 중요합니다` | 강조만 하고 근거 없음 |
| `핵심적입니다` | 남용 |
| `효과적입니다` | 남용 |
| `지속가능한` | 유행어 |
| `혁신적입니다` | 유행어 |
| `주목할 만하다` | 남용 |
| `시사하는 바가 크다` | 남용 |
| `귀중한 통찰` | 남용 |

**교정 원칙**: 삭제하거나 **구체적 사실로 바꾼다.**

```
❌ 결론적으로, 이 지표는 매우 중요합니다.
✅ 이 지표를 보면 다음 달 지출 계획을 세울 수 있습니다.

❌ 다양한 측면에서 혁신적인 변화입니다.
✅ 결제 절차가 3단계에서 1단계로 줄었습니다.
```

### 채우기용 구조

게이트가 **구조로 판정**한다 (패턴이 아니다).

- 리스트 항목이 **3개 미만**
- 리스트의 **모든 항목이 12자 이하**인 한 줄짜리

```
❌ (채우기용)
- 가격
- 품질
- 배송

✅ (실질 내용)
- 가격: 같은 용량 기준 20% 저렴합니다.
- 품질: 원산지 표기가 명확하고 등급이 표시됩니다.
- 배송: 평일 오후 2시 이전 주문은 다음 날 도착합니다.
```

## 등급 산정

서버가 S1/S2 개수로 계산한다.

| 등급 | 조건 | 발행 |
|---|---|---|
| A | S1 0 + S2 ≤2 | ✅ |
| B | S1 ≤2 + S2 ≤5 | ✅ |
| C | S1 ≤4 + S2 ≤9 | ❌ |
| D | 그 외 | ❌ |

## 목표는 "자연스러움"이지 "완벽함"이 아니다

- 모든 문장을 짧게 쪼개면 오히려 기계적으로 읽힌다. 길이를 섞어라.
- 접속사를 전부 지우면 문단이 끊긴다. 필요한 곳에는 남겨라.
- 같은 표현이 반복되는 것을 지나치게 피하면 부자연스러워진다.
- **원문의 의미와 사실을 바꾸지 않는 선에서만** 다듬어라.
