# 본문 구조 규칙

서버(`AIAP_Writing_Guide::structure()`)와 동일한 값이다.

## 구조

| 항목 | 기준 |
|---|---|
| 도입부 | 2~3문단 |
| 첫 200자 안 메인 키워드 | 1회 포함 |
| H2 | 3~12개 |
| 각 H2 아래 첫 문단 | 3문장 이상 |
| 결론 | 마지막 H2 뒤 짧은 결론 |
| 리스트 또는 표 | 1개 이상 |
| 내부 링크 | 1개 이상 |
| 외부 링크 | 최대 3개 |
| 키워드 밀도 | 맞추지 않는다 (아래 참고) |

## 배치

```
[도입부 2~3문단]           ← 첫 문단 앞쪽에 메인 키워드
[H2] 섹션 1
  문단 (3문장 이상)
  필요시 H3 / 리스트 / 표
[H2] 섹션 2
  ...
[결론] 짧게
```

## 키워드 밀도

**맞추지 않는다.** 네이버·구글 공식 문서에는 적정 밀도 수치가 없다. 서버 게이트도 밀도를 검사하지 않는다.

- 키워드는 제목, 도입부, H2 하나에 자연스럽게 들어가면 충분하다.
- 같은 키워드를 억지로 반복하지 마라. 네이버는 반복 사용을 품질 저하로 본다.

## 제목·메타 설명

길이와 온페이지 SEO 점수는 SEO 플러그인(KDR SEO 등)이 판정한다. 이 스킬은 따로 기준을 두지 않는다.
`aiap/create-post` 의 `focusKeyword`·`metaDescription` 으로 넘기면 켜져 있는 SEO 플러그인에 저장된다.

## 링크

| 종류 | 기준 | 주의 |
|---|---|---|
| 내부 | 1개 이상 | 실제 존재하는 자기 사이트 URL |
| 외부 | 0~3개 | **실제 확인한 URL만.** 확인 불가면 넣지 않는다 |

외부 링크를 "개수 채우기"로 만들면 **발행 게이트가 거부한다.**
`references/fabrication-guard.md` 참조.

## 리스트와 표

- **점수 채우기용으로 만들지 마라.** 서버가 구조로 판정한다.
  - 항목 3개 미만 → 위반
  - 모든 항목이 12자 이하 → 위반
- 비교·단계·항목 나열처럼 **정말 나열이 맞는 곳**에만 쓴다.
- 서술이 자연스러운 곳에는 문장을 쓴다.

## 글자수

`aiap/analyze-keyword` 응답의 `target_chars` 를 기준으로 한다.

| KD | 권장 |
|---|---|
| < 35 | 1,200자 |
| < 65 | 1,800자 |
| ≥ 65 | 2,600자 |

게이트는 **권장의 70% 이상**을 요구한다. 70% 미만이면 `length` 게이트에서 거부된다.

## 이미지

- 본문 이미지는 능력으로 직접 넣지 않는다. WordPress 미디어로 등록한 뒤
  `aiap/update-post` 로 본문에 배치한다.
- 모든 이미지에 `alt` 를 넣는다 (SEO 플러그인이 alt 누락을 검사한다).
