# 발명 금지 (Fabrication Guard) — S1

이 문서는 **이 플러그인 고유** 범주다. 참고한 일반 윤문 스킬들에는 없는 항목이며,
실제 사고에서 유입됐다.

## 왜 별도 범주인가

문체(번역투·상투어)를 아무리 다듬어도 **없는 사실을 지어내면** 그 글은 실패다.
검색엔진에는 저품질 신호이고, 독자에게는 신뢰 상실이며, 깨진 링크는 이탈로 이어진다.

## 실제 사고 (2026-10, b014.wordsense.kr)

발행된 글에 이런 링크가 들어 있었다.

```html
<a href="https://example.com/reports/2026/consumer-price-index-detailed-methodology-and-regional-breakdown-appendix?utm_source=daily-pick&utm_medium=referral">장문 URL 예시 링크</a>
```

그리고 본문에 이런 문장이 있었다.

> 생활 물가에 관한 더 많은 이야기는 **샘플**에서 다룹니다.

**원인 추정**: "외부 링크를 1개 이상 넣어라" 는 요구를 생성 파이프라인이
**리터럴 플레이스홀더로 채웠다.** 앵커 텍스트 `장문 URL 예시 링크` 자체가
템플릿 문구가 그대로 새어 나온 증거다.

**교훈**: "외부 링크를 넣어라"는 요구는 **"실제로 존재하는 링크를 넣어라"** 로
이해해야 한다. 확인할 수 없으면 **링크를 넣지 않는 것이 정답**이다.

## 금지 목록

### URL

| 금지 패턴 | 비고 |
|---|---|
| `example.com` / `example.org` / `example.net` / `example.edu` | 예약 도메인 |
| `placeholder` | 문자열 자체 |
| `yourdomain`, `your-domain`, `도메인.com` | 자리표시자 |
| `/reports/20XX/...-appendix` | 사고 사례의 형태 |

### 앵커 텍스트

- `URL 예시`
- `장문 URL 예시 링크`
- `예시 링크`
- `여기에 링크`
- `출처 링크 삽입`

### 템플릿 잔여어

| 금지 | 이유 |
|---|---|
| `샘플` (조사 결합 포함: `샘플에서`, `샘플을`) | 플레이스홀더가 본문에 노출 |
| `TODO`, `FIXME`, `XXX` | 미완성 표시 |
| `여기에 입력`, `여기에 작성` | 자리표시자 |
| `{{ }}`, `${ }` | 템플릿 문법 |
| `Lorem ipsum` | 더미 텍스트 |
| 끝에 남은 `[ ... ]` | 미채움 괄호 |

### 자기 참조 placeholder

- `~에서 다룹니다`
- `~를 참고하세요`
- `위 내용을 참조`

이 표현들은 **다른 문서를 가리키는 척하면서 실제로는 아무것도 가리키지 않는다.**

## 올바른 처리

### 링크가 필요할 때

1. **실제로 접근해 확인한다** — `web_fetch` 등으로 응답을 확인
2. 확인되면 그 URL 과 **실제 문서 제목**을 앵커로 쓴다
3. 확인되지 않으면 **링크를 넣지 않는다.** 그 문장을 다시 쓴다

```
❌ 자세한 내용은 [장문 URL 예시 링크](https://example.com/...)에서 확인할 수 있습니다.
✅ 세계보건기구의 [식이 지침](https://www.who.int/...)에서 기준을 확인할 수 있습니다.
✅ (링크를 확인할 수 없을 때) 기준은 국가별로 다르므로 거주 국가의 보건 당국 자료를 확인하십시오.
```

### 통계·수치가 필요할 때

- 출처를 확인할 수 있으면 **출처와 함께** 쓴다
- 확인할 수 없으면 **구체적 수치를 쓰지 않는다.** 정성적 서술로 바꾼다

```
❌ 국내 홈트 시장은 2026년 3조 원 규모로 성장했습니다.
✅ 홈트 시장은 최근 몇 년간 빠르게 커졌습니다.
```

## 검사 방법

`aiap/check-content-quality` 를 호출하면 `counts.S1` 과 `hits.S1` 에 이 범주 위반이
담긴다. `checks.links_verified` 가 `false` 이고 `metrics.dummy_links` 가 1 이상이면
발행 게이트가 거부한다.

```
aiap/check-content-quality { content, title, keyword }
  → { counts: { S1: 3 }, hits: { S1: [...] }, checks: { links_verified: false } }
```

발행 전에 **반드시** 이 검사를 통과시켜라. 서버가 발행 시점에 다시 검사한다.
